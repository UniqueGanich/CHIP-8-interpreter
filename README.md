# CHIP-8 Interpreter
> A training project to create an interpreter.\

## English
GAME SET\
The emulator takes games from the “games” folder, which CANNOT be renamed!\
You can add files with the ending ".ch8" or ".rom" there yourself.\
The list of games will be displayed when you launch the emulator.

management\
The original CHIP-8 has 16 keys; we use the following keys:\
1 2 3 4\
 Q W E R\
  A S D F\
   Z X C V

We also use 2 layout variations:\
“Standard” — used by most people\
“Linear” — for unique programs\
Unfortunately, we don’t know the controls for specific games, nor what layout they need.\
You’ll have to learn the controls and find the layout yourself.\
Use “Standard” by default; if the controls seem strange, try switching to “Linear.”\
If it only gets worse, go back to “Standard” — the controls were really strange back then.

STABILITY AND GAMES\
There are strange games, possibly non‑functional ones; there are demo games, and there are even multiplayer games!
